# Fundamentals of Data Science – Lab Experiments

## About
This repository contains the laboratory experiments performed as part of the **Fundamentals of Data Science (FDS)** course. It documents practical work covering data analysis, visualization, statistical techniques, data preprocessing, and machine learning using Python.

## Experiments Covered
- **Data Analysis:** Analyzing datasets, exploring data science job trends, and understanding different types of data.
- **Data Visualization:** Representing data using line plots, bar charts, pie charts, Matplotlib, and Seaborn.
- **Data Preprocessing:** Handling missing values, detecting outliers, cleaning datasets, and applying feature scaling.
- **Statistical Analysis:** Performing random sampling, studying sampling distributions, analyzing time series, and conducting Z-tests.
- **Exploratory Data Analysis (EDA):** Exploring quantitative and qualitative data to identify patterns and useful insights.
- **Machine Learning:** Implementing Linear Regression, K-Nearest Neighbors (KNN), Logistic Regression, and K-Means Clustering.
- **Other Experiments:** Word frequency analysis, array operations, and data encryption and decryption using Fernet.

## Tools and Technologies
- **Programming Language:** Python
- **Data Manipulation:** NumPy, Pandas
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Data Security:** Cryptography library

## Repository Contents
This repository includes individual PDF records of the laboratory experiments for easy reference and revision.

## Learning Objectives
- Understand fundamental concepts of Data Science.
- Gain practical experience in data analysis and visualization.
- Learn data cleaning and preprocessing techniques.
- Apply statistical methods to analyze datasets.
- Understand and implement basic machine learning algorithms.

## Purpose
The purpose of this repository is to document laboratory work, strengthen practical programming skills, and build a foundation in Data Science through hands-on experiments.
